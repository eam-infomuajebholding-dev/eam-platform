# Project Summary
A Saudi Arabian engineering consultancy platform for EAM Engineering Consultancy. It presents the company’s services, projects, team, investment opportunities, careers, and contact information while collecting consultation requests and managing business content through an administrative dashboard. The platform also provides AI-assisted visitor support, media management, notifications, and OIDC-based administrator authentication.

# Project Module Description
- **Public Website**: Homepage, company profile, engineering and general services, investment, projects, team, market, careers, contact, and digital business card pages.
- **Consultation Management**: Collects and stores consultation requests for administrative follow-up.
- **Contact Management**: Handles visitor contact messages.
- **AI Chatbot**: Provides automated visitor assistance.
- **Admin Dashboard**: Supports protected content management and inline editing.
- **Section Manager**: Adds, removes, and reorganizes editable page sections.
- **Page Manager**: Manages custom pages and navigation links.
- **Page Background Editor**: Customizes page background presentation.
- **OIDC Authentication**: Uses Atoms Cloud OIDC for administrator login, token exchange, validation, and logout.
- **Notifications**: Sends submission-related alerts.
- **Media Management**: Supports Cloudinary-based uploads and storage.
- **Database Layer**: Persists content, submissions, users, and related application data.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: PostgreSQL with Alembic migrations
- **Authentication**: OpenID Connect through Atoms Cloud
- **Notifications**: Atoms Cloud
- **Storage**: Cloudinary and IndexedDB
- **Deployment Support**: AWS Lambda handler and shell-based startup

# Usage
1. Install backend dependencies:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```

2. Install frontend dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```

3. Create an environment file from `.env.example`. Configure the current Atoms Cloud OIDC settings:
   ```env
   OIDC_ISSUER_URL=https://auth.atoms.dev/api/v1/oidc
   OIDC_CLIENT_ID=dd6fe8bd06944a0c9e6c76d16ea1ab09
   OIDC_CLIENT_SECRET=<runtime secret>
   OIDC_SCOPE=openid email
   ```
   The client secret is supplied by the runtime environment and must not be committed to files or exposed in logs. Configure the database, frontend, backend, and Cloudinary settings as required.

4. Register the backend authentication callback and frontend logout callback with the OIDC provider. The current Atoms Cloud client is tied to Atoms-managed domains; deployments on independent domains require a new OIDC client from an independently managed provider such as Auth0, Keycloak, or AWS Cognito.

5. Run database migrations:
   ```bash
   cd app/backend
   alembic upgrade head
   ```

6. Start the backend:
   ```bash
   cd app/backend
   uvicorn main:app --reload
   ```

7. Start the frontend:
   ```bash
   cd app/frontend
   pnpm run dev
   ```

8. For the configured application runtime:
   ```bash
   cd app
   ./start_app_v2.sh
   ```
