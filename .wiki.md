# Project Summary
This project is a web application providing consultation services that allow users to submit requests and contact messages stored in a database. It automates confirmation notifications for successful submissions. Enhanced by Atoms Cloud integration, the project offers efficient data management and notification capabilities for users and administrators. Recent enhancements include a floating WhatsApp button on the Contact page, an "About Us" page, an AI chatbot for real-time assistance, a light/dark mode toggle, and now scroll-based reveal animations for an engaging user experience.

# Project Module Description
- **Backend**: Manages data storage, processing, and business logic.
- **Frontend**: User interface for submitting consultation requests and contact messages, featuring an updated logo design, new pages, an AI chatbot, light/dark mode toggle, and scroll-based animations.
- **Notifications Service**: Sends confirmation emails to users.
- **Database**: Stores user submissions and related data.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: PostgreSQL (via Alembic for migrations)
- **Notification Service**: Atoms Cloud

# Usage
1. Install backend dependencies:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```
2. Install frontend dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```
3. Run database migrations (if applicable):
   ```bash
   alembic upgrade head
   ```
4. Start the backend server:
   ```bash
   cd app/backend
   uvicorn main:app --reload
   ```
5. Start the frontend development server:
   ```bash
   cd app/frontend
   pnpm run dev
   ```
