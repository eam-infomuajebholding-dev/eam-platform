# Furnishing Journey V1 (#15)

## Purpose

Help a customer establish furnishing readiness and convert intake into a qualified professional service request.

## Journey type

- `furnishing`
- Sector slug: `furnishing`
- Service request prefix: `FR-*`

## First Value

- Title: **موجز جاهزية التأثيث والتجهيز**
- Status: `PRELIMINARY` / `RULE_ASSISTED`
- No fabricated prices, supplier availability, or delivery guarantees

## Flow

`space_type` → `project_stage` → `furnishing_goal` → `style_direction` → `functional_priorities` → `room_scope` → `budget_range` → `timeline_context` → `procurement_preference` → `readiness_context` → review → explicit submit → one Service Request

## AI intent

Deterministic phrases include: تأثيث المنزل، تجهيز مكتب، furnish my home, office furnishing

## Marketplace demand signal

May indicate future need for supplier matching / procurement coordination — not implemented in V1.
