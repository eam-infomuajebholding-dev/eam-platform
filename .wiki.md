# Project Summary
This project is a web application designed for an engineering consulting company, providing comprehensive consultation services. Users can submit requests and messages, which are efficiently managed through a database. The application automates confirmation notifications for submitted requests and integrates with Atoms Cloud for streamlined data handling. Recent enhancements include a redesigned admin dashboard that aligns with the website's dark/gold theme and supports inline editing of all content, including text, images, videos, and sections. An AI chatbot for real-time assistance and a user-friendly interface with light/dark mode transitions further enhance the user experience.

# Project Module Description
- **Backend**: Handles data storage, processing, and business logic.
- **Frontend**: User interface for consultation requests, featuring an AI chatbot and light/dark mode toggle.
- **Notifications Service**: Sends confirmation notifications to users.
- **Database**: Stores user submissions and related data.
- **Admin Dashboard**: Facilitates management of site content, including pages, services, projects, and settings, now with improved inline editing capabilities.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: PostgreSQL (via Alembic for migrations)
- **Notification Service**: Atoms Cloud

# Usage
1. Install backend dependencies:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```
2. Install frontend dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```
3. Run database migrations (if applicable):
   ```bash
   alembic upgrade head
   ```
4. Start the backend server:
   ```bash
   cd app/backend
   uvicorn main:app --reload
   ```
5. Start the frontend development server:
   ```bash
   cd app/frontend
   pnpm run dev
   ```
