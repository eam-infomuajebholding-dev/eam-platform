# Usage
1. Install backend dependencies:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```

2. Install frontend dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```

3. Configure the environment from `.env.example`. Set OIDC, database, backend, frontend, and external-service variables. Keep secrets outside version control.

4. Ensure `OIDC_CLIENT_SECRET` is set and non-empty without exposing its value.

5. Run database migrations:
   ```bash
   cd app/backend
   alembic upgrade head
   ```

6. Start the backend:
   ```bash
   cd app/backend
   uvicorn main:app --reload
   ```

7. Start the frontend:
   ```bash
   cd app/frontend
   pnpm run dev
   ```

8. Start the configured application runtime:
   ```bash
   cd app
   ./start_app_v2.sh
   ```

9. Validate backend syntax:
   ```bash
   cd app/backend
   python3 -m py_compile main.py core/config.py routers/auth.py
   ```

10. Before synchronization, export `/root/eam-atoms-backup-20260907-071713` to durable private storage, independently verify canonical commit `d258228`, and review the local OIDC/environment changes. Do not reset, merge, push, or overwrite the workspace until those checks are complete.
