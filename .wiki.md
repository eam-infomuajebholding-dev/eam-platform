# Project Summary
A Saudi Arabian engineering consultancy platform for EAM Engineering Consultancy. It showcases the company’s services, projects, team, investment opportunities, careers, and contact channels while collecting consultation and contact requests. Administrators manage business content through a protected dashboard with inline editing, media tools, page and section management, notifications, AI visitor assistance, and OIDC authentication.

# Project Module Description
- **Public Website**: Homepage, company profile, engineering and general services, investment, projects, team, market, careers, contact, and digital business card pages.
- **Consultation Management**: Collects consultation requests for administrative follow-up.
- **Contact Management**: Handles visitor contact messages.
- **AI Chatbot**: Provides automated visitor support.
- **Admin Dashboard**: Provides protected content management and inline editing.
- **Section Manager**: Adds, removes, and reorganizes editable page sections.
- **Page Manager**: Manages custom pages and navigation links.
- **Page Background Editor**: Customizes page backgrounds.
- **OIDC Authentication**: Handles administrator login, callbacks, token exchange, validation, and logout through Atoms Cloud OIDC.
- **Dynamic Redirect Handling**: Uses forwarded protocol information and keeps local hosts on HTTP while preserving HTTPS for non-local deployments.
- **Environment Configuration**: Centrally loads environment files before settings initialization, with system environment variables taking precedence.
- **Notifications**: Sends submission-related alerts.
- **Media Management**: Supports Cloudinary uploads and storage.
- **Database Layer**: Persists content, submissions, users, and application data.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: PostgreSQL with Alembic migrations
- **Authentication**: OpenID Connect through Atoms Cloud
- **Configuration**: `python-dotenv` with environment precedence
- **Notifications**: Atoms Cloud
- **Storage**: Cloudinary and IndexedDB
- **Deployment Support**: AWS Lambda handler and shell-based startup

# Usage
1. Install backend dependencies:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```

2. Install frontend dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```

3. Create the runtime environment from `.env.example`. Configure the required OIDC, database, frontend, and external-service variables. Keep real secrets only in ignored environment files or the deployment environment.

4. Environment loading is centralized in `backend/core/config.py`. It checks `app/.env` and then `app/backend/.env`; variables already exported by the runtime take precedence.

5. Register the callback address produced by the authentication flow in the OIDC client configuration. Local hosts use HTTP, while forwarded production requests and non-local hosts use HTTPS. Ensure the host used for local testing matches the registered OIDC configuration.

6. Run database migrations:
   ```bash
   cd app/backend
   alembic upgrade head
   ```

7. Start the backend:
   ```bash
   cd app/backend
   uvicorn main:app --reload
   ```

8. Start the frontend:
   ```bash
   cd app/frontend
   pnpm run dev
   ```

9. Start the configured application runtime:
   ```bash
   cd app
   ./start_app_v2.sh
   ```

10. Validate the backend changes:
   ```bash
   cd app/backend
   python3 -m py_compile main.py core/config.py routers/auth.py
   ```
