# Project Summary
A Saudi Arabian engineering consultancy platform for EAM Engineering Consultancy. It presents company services, projects, team information, investment opportunities, careers, and contact channels while collecting consultation and contact requests. Administrators manage business content through a protected dashboard with inline editing, media tools, page and section management, notifications, AI visitor assistance, and OIDC authentication.

# Usage
1. Install backend dependencies:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```

2. Install frontend dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```

3. Configure the environment from `.env.example`. Set OIDC, database, backend, frontend, and external-service variables. Keep secrets outside version control.

4. Ensure `OIDC_CLIENT_SECRET` is set and non-empty without exposing its value.

5. Run database migrations:
   ```bash
   cd app/backend
   alembic upgrade head
   ```

6. Start the backend:
   ```bash
   cd app/backend
   uvicorn main:app --reload
   ```

7. Start the frontend:
   ```bash
   cd app/frontend
   pnpm run dev
   ```

8. Start the configured application runtime:
   ```bash
   cd app
   ./start_app_v2.sh
   ```

9. Validate backend syntax:
   ```bash
   cd app/backend
   python3 -m py_compile main.py core/config.py routers/auth.py
   ```

10. Do not synchronize to `d258228` until the current workspace is exported or backed up and the canonical versions of `auth.py` and `config.py` are verified. The current workspace contains OIDC and environment-loading fixes that may otherwise be lost.
