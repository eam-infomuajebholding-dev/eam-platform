# Project Summary
This project is a dynamic web application created for an engineering consulting firm. It streamlines the consultation request process and manages submissions through a robust database. The application automates notifications and integrates with Cloudinary for efficient media handling. Key features include a modern admin dashboard, advanced management tools, a responsive AI chatbot for user support, and a user-friendly interface. Recent updates have enhanced the homepage, improved database interactions, and refined the admin dashboard and team pages.

# Project Module Description
- **Backend**: Manages data storage, processing, and business logic.
- **Frontend**: User interface for consultation requests, featuring an AI chatbot and light/dark mode toggle.
- **Notifications Service**: Sends notifications upon submission confirmation.
- **Database**: Stores user submissions and related data.
- **Admin Dashboard**: Facilitates content management with inline editing capabilities.
- **Section Manager**: Allows adding and deleting sections in edit mode.
- **Page Manager**: Manages custom navigation links and pages.
- **Page Background Editor**: Customizes page backgrounds.
- **Projects Page**: Displays ongoing and completed projects.
- **Team Page**: Showcases team members.
- **Cloudinary Integration**: Supports cloud-based media uploads.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: PostgreSQL (via Alembic for migrations)
- **Notification Service**: Atoms Cloud
- **Storage**: IndexedDB for persistent media storage
- **Cloudinary**: For cloud-based media uploads

# Usage
1. Install backend dependencies:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```
2. Install frontend dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```
3. Configure Cloudinary by creating a `.env` file with the following content:
   ```
   VITE_CLOUDINARY_CLOUD_NAME=<your_cloud_name>
   VITE_CLOUDINARY_UPLOAD_PRESET=<your_upload_preset>
   ```
4. Run database migrations (if applicable):
   ```bash
   alembic upgrade head
   ```
5. Start the backend server:
   ```bash
   cd app/backend
   uvicorn main:app --reload
   ```
6. Start the frontend development server:
   ```bash
   cd app/frontend
   pnpm run dev
   ```
