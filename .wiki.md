# Project Summary
This project is a dynamic web application designed for an engineering consulting firm. It streamlines the consultation request process and enhances submission management through a robust database. The system automates notifications and utilizes Atoms Cloud for efficient data handling. Key features include an updated admin dashboard, improved management of sections and pages, a responsive AI chatbot for user support, and integration with Cloudinary for media uploads. Recent enhancements include a more accessible dark mode, full-screen media uploads, and a user-friendly interface.

# Project Module Description
- **Backend**: Manages data storage, processing, and business logic.
- **Frontend**: Provides the user interface for consultation requests, featuring an AI chatbot and a toggle for light/dark mode.
- **Notifications Service**: Sends confirmation notifications to users upon submission.
- **Database**: Stores user submissions and related data.
- **Admin Dashboard**: Facilitates content management with inline editing capabilities.
- **Section Manager**: Enables the addition and deletion of sections in edit mode.
- **Page Manager**: Oversees custom navigation links and pages, supporting full-screen media.
- **Page Background Editor**: Allows customization of page backgrounds with colors, images, or videos.
- **Projects Page**: Displays ongoing and completed projects, allowing for project management functionalities.
- **Team Page**: Highlights team members with functionalities for management.
- **Cloudinary Integration**: Supports cloud-based media uploads for images and videos.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: PostgreSQL (via Alembic for migrations)
- **Notification Service**: Atoms Cloud
- **Storage**: IndexedDB for persistent media storage
- **Cloudinary**: For cloud-based media uploads

# Usage
1. Install backend dependencies:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```
2. Install frontend dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```
3. Run database migrations (if applicable):
   ```bash
   alembic upgrade head
   ```
4. Start the backend server:
   ```bash
   cd app/backend
   uvicorn main:app --reload
   ```
5. Start the frontend development server:
   ```bash
   cd app/frontend
   pnpm run dev
   ```
