# Project Summary
A Saudi Arabian engineering consultancy platform for EAM Engineering Consultancy. The product presents the company’s services, projects, team, investment opportunities, careers, and contact channels while collecting consultation and contact requests. Administrators manage business content through a protected dashboard with inline editing, media tools, page and section management, notifications, AI visitor assistance, and OIDC authentication.

The application code supports OIDC authentication, but external login remains blocked until Atoms Cloud registers the required callback address for the configured client. The production `backend_url` must also be replaced wherever the `$$BACKEND_DOMAIN$$` placeholder remains. Local environment configuration contains an OIDC client secret and must be maintained separately from the repository.

# Project Module Description
- **Public Website**: Homepage, company profile, engineering and general services, investment, projects, team, market, careers, contact, and digital business card pages.
- **Consultation Management**: Collects consultation requests for administrative follow-up.
- **Contact Management**: Handles visitor contact messages.
- **AI Chatbot**: Provides automated visitor support.
- **Admin Dashboard**: Provides protected content management and inline editing.
- **Section Manager**: Adds, removes, and reorganizes editable page sections.
- **Page Manager**: Manages custom pages and navigation links.
- **Page Background Editor**: Customizes page backgrounds.
- **OIDC Authentication**: Handles administrator login, callbacks, token exchange, validation, and logout through Atoms Cloud.
- **Redirect Handling**: Derives callback redirects from request and forwarded-protocol information, using HTTP for local hosts and HTTPS for non-local deployments.
- **Environment Configuration**: Loads environment files centrally while allowing exported system variables to take precedence.
- **Notifications**: Sends submission-related alerts.
- **Media Management**: Supports Cloudinary uploads and storage.
- **Database Layer**: Persists content, submissions, users, and application data.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: PostgreSQL with Alembic migrations
- **Authentication**: OpenID Connect through Atoms Cloud
- **Configuration**: `python-dotenv` with environment precedence
- **Notifications**: Atoms Cloud
- **Storage**: Cloudinary and IndexedDB
- **Deployment Support**: AWS Lambda handler and shell-based startup

# Usage
1. Install backend dependencies:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```

2. Install frontend dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```

3. Create the runtime environment from `.env.example`. Configure the OIDC issuer, client ID, client secret, scope, database, backend, frontend, and external-service variables. Keep secrets only in ignored environment files or the deployment environment.

4. Verify that `app/.env` contains the required OIDC variables, including a non-empty `OIDC_CLIENT_SECRET`. Do not print or commit secret values.

5. Replace every unresolved `$$BACKEND_DOMAIN$$` placeholder with the deployed backend domain before production use.

6. Register the exact callback address generated by the authentication flow in the Atoms Cloud client configuration. Local and production protocol behavior must match the registered address. The current client has no accepted local callback until the provider configuration is updated.

7. Environment loading is centralized in `backend/core/config.py`. It checks the application and backend environment files while exported runtime variables take precedence.

8. Run database migrations:
   ```bash
   cd app/backend
   alembic upgrade head
   ```

9. Start the backend:
   ```bash
   cd app/backend
   uvicorn main:app --reload
   ```

10. Start the frontend:
   ```bash
   cd app/frontend
   pnpm run dev
   ```

11. Start the configured application runtime:
   ```bash
   cd app
   ./start_app_v2.sh
   ```

12. Validate backend changes:
   ```bash
   cd app/backend
   python3 -m py_compile main.py core/config.py routers/auth.py
   ```
