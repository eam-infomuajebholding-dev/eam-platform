# Project Summary
The project is a comprehensive web application designed for EAM Engineering Consultancy, an engineering consulting firm based in Saudi Arabia. It focuses on optimizing the consultation request process and managing submissions through a robust database. The application features an AI-powered chatbot for user support, an advanced admin dashboard, and seamless integration with Cloudinary for media handling. Recent enhancements include improved user experience and updates to various components, ensuring a modern and efficient interface.

# Project Module Description
- **Backend**: Handles data storage, processing, and business logic using FastAPI.
- **Frontend**: Built with React and TypeScript, providing a user-friendly interface for consultation requests and features like an AI chatbot.
- **Notifications Service**: Manages alerts upon submission confirmations.
- **Database**: Utilizes PostgreSQL to store user submissions and related data.
- **Admin Dashboard**: Facilitates content management with inline editing capabilities.
- **Section Manager**: Enables adding and deleting sections in edit mode.
- **Page Manager**: Manages custom navigation links and pages.
- **Page Background Editor**: Allows customization of page backgrounds.
- **Projects Page**: Displays ongoing and completed projects.
- **Team Page**: Showcases team members.
- **Cloudinary Integration**: Supports cloud-based media uploads and storage.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: PostgreSQL (via Alembic for migrations)
- **Notification Service**: Atoms Cloud
- **Storage**: IndexedDB for persistent media storage
- **Cloudinary**: For cloud-based media uploads

# Usage
1. Install backend dependencies:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```
2. Install frontend dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```
3. Configure Cloudinary by creating a `.env` file with the following content:
   ```
   VITE_CLOUDINARY_CLOUD_NAME=<your_cloud_name>
   VITE_CLOUDINARY_UPLOAD_PRESET=<your_upload_preset>
   ```
4. Run database migrations (if applicable):
   ```bash
   alembic upgrade head
   ```
5. Start the backend server:
   ```bash
   cd app/backend
   uvicorn main:app --reload
   ```
6. Start the frontend development server:
   ```bash
   cd app/frontend
   pnpm run dev
   ```
