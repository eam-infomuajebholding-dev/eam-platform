# Project Summary
A Saudi Arabian engineering consultancy platform for EAM Engineering Consultancy. The product presents company services, projects, team information, investment opportunities, careers, and contact channels while collecting consultation and contact requests. Administrators manage business content through a protected dashboard with inline editing, media tools, page and section management, notifications, AI visitor assistance, and OIDC authentication.

The canonical source is the GitHub `main` branch at commit `d258228`, which contains the modern EAM homepage and M1 baseline. The current Atoms workspace has not been synchronized because it contains six unpublished commits and one uncommitted file, while the canonical commit could not be fetched due to unavailable GitHub credentials and a read-only Git workspace. The workspace therefore continues to serve the legacy consultancy website.

# Project Module Description
- **Public Website**: Homepage, company profile, engineering and general services, investment, projects, team, market, careers, contact, and digital business card pages.
- **Consultation Management**: Collects consultation requests for administrative follow-up.
- **Contact Management**: Handles visitor contact messages.
- **AI Chatbot**: Provides automated visitor support.
- **Admin Dashboard**: Provides protected content management and inline editing.
- **Section Manager**: Adds, removes, and reorganizes editable page sections.
- **Page Manager**: Manages custom pages and navigation links.
- **Page Background Editor**: Customizes page backgrounds.
- **OIDC Authentication**: Handles administrator login, callbacks, token exchange, validation, and logout through Atoms Cloud.
- **Notifications**: Sends submission-related alerts.
- **Media Management**: Supports Cloudinary uploads and storage.
- **Database Layer**: Persists content, submissions, users, and application data.
- **Canonical M1 Modules**: HeroChat, QuickActions, WorkspaceProvider, Build Villa handoff, JOS, AI Core, and Service Requests are expected in commit `d258228` but are not present in the current workspace.

- **Authentication**: OpenID Connect through Atoms Cloud
- **Configuration**: `python-dotenv` with environment precedence
- **Notifications**: Atoms Cloud
- **Storage**: Cloudinary and IndexedDB
- **Deployment**: AWS Lambda support and shell-based startup
- **Source Control**: GitHub `main` as the canonical source

# Usage
1. Install backend dependencies:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```

2. Install frontend dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```

3. Copy `.env.example` to the runtime environment and configure OIDC, database, backend, frontend, and external-service variables. Keep secrets outside version control.

4. Ensure `OIDC_CLIENT_SECRET` is set and non-empty without exposing its value.

5. Run database migrations:
   ```bash
   cd app/backend
   alembic upgrade head
   ```

6. Start the backend:
   ```bash
   cd app/backend
   uvicorn main:app --reload
   ```

7. Start the frontend:
   ```bash
   cd app/frontend
   pnpm run dev
   ```

8. Start the configured application runtime:
   ```bash
   cd app
   ./start_app_v2.sh
   ```

9. Validate backend syntax:
   ```bash
   cd app/backend
   python3 -m py_compile main.py core/config.py routers/auth.py
   ```

10. Do not synchronize or overwrite the current workspace until the six unpublished commits and one uncommitted file are reviewed and either preserved or explicitly discarded. The canonical commit remains unavailable locally until GitHub access is restored.
