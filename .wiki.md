# Project Summary
A Saudi Arabian engineering consultancy platform for EAM Engineering Consultancy. The application presents the company’s services, projects, team, investment opportunities, careers, and contact information while collecting consultation requests and managing business content through an admin dashboard. It also provides AI-assisted visitor support, media management, notifications, and OIDC-based administrator authentication.

# Project Module Description
- **Public Website**: Homepage, company profile, engineering and general services, investment, projects, team, market, careers, contact, and digital business card pages.
- **Consultation Management**: Collects and stores consultation requests for administrative follow-up.
- **Contact Management**: Handles visitor contact messages.
- **AI Chatbot**: Provides automated visitor assistance.
- **Admin Dashboard**: Supports protected content management and inline editing.
- **Section Manager**: Adds, removes, and reorganizes editable page sections.
- **Page Manager**: Manages custom pages and navigation links.
- **Page Background Editor**: Customizes page background presentation.
- **OIDC Authentication**: Uses an external identity provider for administrator login, token exchange, validation, and logout.
- **Notifications**: Sends submission-related alerts.
- **Media Management**: Supports Cloudinary-based uploads and storage.
- **Database Layer**: Persists content, submissions, users, and related application data.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: PostgreSQL with Alembic migrations
- **Authentication**: OpenID Connect (OIDC)
- **Notifications**: Atoms Cloud
- **Storage**: Cloudinary and IndexedDB
- **Deployment Support**: AWS Lambda handler and shell-based startup

# Usage
1. Install backend dependencies:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```

2. Install frontend dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```

3. Create an environment file from `.env.example` and configure:
   ```env
   OIDC_ISSUER_URL=
   OIDC_CLIENT_ID=
   OIDC_CLIENT_SECRET=
   OIDC_SCOPE=openid profile email
   ```
   Also provide the project’s database, frontend, backend, and Cloudinary settings as required.

4. Register the backend authentication callback and frontend logout callback with the OIDC provider according to the deployment environment.

5. Run database migrations:
   ```bash
   cd app/backend
   alembic upgrade head
   ```

6. Start the backend:
   ```bash
   cd app/backend
   uvicorn main:app --reload
   ```

7. Start the frontend:
   ```bash
   cd app/frontend
   pnpm run dev
   ```

8. For the configured application runtime, use:
   ```bash
   cd app
   ./start_app_v2.sh
   ```
