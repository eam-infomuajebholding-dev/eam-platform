# Project Summary
This project is a comprehensive web application designed for an engineering consulting firm. It allows users to submit consultation requests and messages while managing these submissions through a robust database. The application automates notifications and integrates with Atoms Cloud for enhanced data management. Recent updates include a revamped admin dashboard with improved content management features, enhanced accessibility options, and a responsive AI chatbot for real-time user assistance. The user interface supports light/dark mode transitions and features persistent video backgrounds for an engaging experience.

# Project Module Description
- **Backend**: Manages data storage, processing, and business logic.
- **Frontend**: Provides the user interface for consultation requests, featuring an AI chatbot and a light/dark mode toggle.
- **Notifications Service**: Sends confirmation notifications to users.
- **Database**: Stores user submissions and associated data.
- **Admin Dashboard**: Facilitates content management with enhanced inline editing capabilities and customization options.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: PostgreSQL (via Alembic for migrations)
- **Notification Service**: Atoms Cloud
- **Storage**: IndexedDB for persistent video backgrounds

# Usage
1. Install backend dependencies:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```
2. Install frontend dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```
3. Run database migrations (if applicable):
   ```bash
   alembic upgrade head
   ```
4. Start the backend server:
   ```bash
   cd app/backend
   uvicorn main:app --reload
   ```
5. Start the frontend development server:
   ```bash
   cd app/frontend
   pnpm run dev
   ```
