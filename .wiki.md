# Usage
1. Install backend dependencies:
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

2. Install frontend dependencies:
   ```bash
   cd frontend
   pnpm install
   ```

3. Copy `.env.example` to the appropriate environment file and configure OIDC, database, backend, frontend, and external-service settings. Keep secrets outside version control.

4. Ensure `OIDC_CLIENT_SECRET` is configured and non-empty.

5. Run database migrations:
   ```bash
   cd backend
   alembic upgrade head
   ```

6. Start the backend:
   ```bash
   cd backend
   uvicorn main:app --reload
   ```

7. Start the frontend:
   ```bash
   cd frontend
   pnpm run dev
   ```

8. Start the configured application runtime:
   ```bash
   ./start_app_v2.sh
   ```

9. Validate backend syntax:
   ```bash
   cd backend
   python3 -m py_compile main.py core/config.py routers/auth.py
   ```

10. For recovery, use the backup manifest. The bundle restores Git history, `gitdir-copy/` restores Git LFS objects, and the worktree archive provides a directly extractable copy containing real binary assets.

11. Before synchronization, export the durable backup to independent private storage, obtain authenticated repository access, and ensure writable Git storage. Do not reset, merge, push, cherry-pick, or replace the workspace until these prerequisites are satisfied.
