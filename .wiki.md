# Project Summary
This project is a web application offering consultation services, enabling users to submit requests and contact messages that are stored in a database. It automates confirmation notifications to users upon successful submissions. The integration with Atoms Cloud enhances data management and notification capabilities, providing an efficient solution for users and administrators. Recent updates include a floating WhatsApp button on the Contact page, an "About Us" page, an AI chatbot for real-time assistance, and now a light/dark mode toggle feature for improved user experience.

# Project Module Description
- **Backend**: Manages data storage, processing, and business logic.
- **Frontend**: User interface for submitting consultation requests and contact messages, featuring an updated logo design, new pages, an AI chatbot, and a light/dark mode toggle.
- **Notifications Service**: Sends confirmation emails to users.
- **Database**: Stores user submissions and related data.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: PostgreSQL (via Alembic for migrations)
- **Notification Service**: Atoms Cloud

# Usage
1. Install backend dependencies:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```
2. Install frontend dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```
3. Run database migrations (if applicable):
   ```bash
   alembic upgrade head
   ```
4. Start the backend server:
   ```bash
   cd app/backend
   uvicorn main:app --reload
   ```
5. Start the frontend development server:
   ```bash
   cd app/frontend
   pnpm run dev
   ```
