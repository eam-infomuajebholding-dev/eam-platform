# Project Summary
This project is a comprehensive web application tailored for an engineering consulting firm. It allows users to submit consultation requests and manage these submissions through a sophisticated database. The application automates notifications and integrates with Atoms Cloud for advanced data management. Recent updates have significantly enhanced the admin dashboard, added section and page management features, and improved user experience with a responsive AI chatbot and a customizable user interface. The application now includes a refined dark mode with updated color schemes for better accessibility.

# Project Module Description
- **Backend**: Manages data storage, processing, and business logic.
- **Frontend**: User interface for consultation requests, featuring an AI chatbot and a light/dark mode toggle.
- **Notifications Service**: Sends confirmation notifications to users.
- **Database**: Stores user submissions and associated data.
- **Admin Dashboard**: Manages content with inline editing capabilities and customization options.
- **Section Manager**: Allows adding and deleting sections in edit mode.
- **Page Manager**: Manages custom navigation links and pages.
- **Page Background Editor**: Enables changing page backgrounds to colors, images, or videos.
- **Projects Page**: Displays ongoing and completed projects with admin functionalities for adding, editing, and deleting projects.
- **Team Page**: Showcases team members with admin functionalities for adding, editing, and deleting team members.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: PostgreSQL (via Alembic for migrations)
- **Notification Service**: Atoms Cloud
- **Storage**: IndexedDB for persistent video backgrounds

# Usage
1. Install backend dependencies:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```
2. Install frontend dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```
3. Run database migrations (if applicable):
   ```bash
   alembic upgrade head
   ```
4. Start the backend server:
   ```bash
   cd app/backend
   uvicorn main:app --reload
   ```
5. Start the frontend development server:
   ```bash
   cd app/frontend
   pnpm run dev
   ```
